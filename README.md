## Setup

- OS: Arch Linux
- WM: Hyprland
- Bar: Waybar
- Terminal: Kitty
- Launcher: Rofi
- Shell: Zsh
- Notifications: SwayNC
- File Manager: Thunar
- Theme: Catppuccin / custom theme
